# Politique de confidentialité — Nouchi Gospel

**Dernière mise à jour : 11 avril 2026**

Cette politique de confidentialité explique comment l'application **Nouchi Gospel** (« l'Application ») collecte, utilise et protège les informations des utilisateurs (« vous »).

En utilisant Nouchi Gospel, vous acceptez les pratiques décrites dans cette politique.

---

## 1. Qui nous sommes

Nouchi Gospel est une application mobile gratuite proposant des versets bibliques traduits en Nouchi, des motivations quotidiennes, la Bible complète et des informations sur des événements chrétiens.

- **Éditeur** : Michel Kouakou
- **Contact** : roschmichel12@gmail.com

---

## 2. Données que nous collectons

### 2.1 Données de compte (optionnel — via Google Sign-In)

Si vous choisissez de vous connecter avec votre compte Google, nous recevons de Google les informations suivantes :
- Votre nom (tel qu'il apparaît sur votre compte Google)
- Votre adresse e-mail
- Votre photo de profil (si disponible)

Ces informations sont utilisées uniquement pour :
- Vous identifier dans l'application
- Personnaliser votre expérience (afficher votre prénom, votre avatar)
- Synchroniser vos préférences entre vos appareils

**Nous n'accédons jamais à vos contacts, vos e-mails, votre agenda ou à tout autre contenu Google.**

### 2.2 Données de notification (push)

Pour vous envoyer le verset du jour, nous utilisons **Firebase Cloud Messaging (FCM)**. Cela génère un identifiant d'appareil anonyme (le « token FCM ») qui permet d'acheminer les notifications vers votre téléphone. Ce token n'est associé à aucune donnée personnelle identifiable.

Vous pouvez désactiver les notifications à tout moment depuis les réglages de votre téléphone.

### 2.3 Données techniques

Comme la plupart des applications mobiles, nous collectons des données techniques minimales via **Firebase** :
- Type d'appareil et système d'exploitation (ex. iPhone 14, iOS 17)
- Version de l'application
- Langue préférée
- Statistiques d'utilisation anonymes (ex. écrans visités, fréquence d'ouverture)

Ces données nous aident à améliorer l'application et à détecter les bugs. Elles ne permettent pas de vous identifier personnellement.

### 2.4 Données stockées localement

Vos préférences (verset favoris, notifications activées, onboarding vu, etc.) sont stockées **uniquement sur votre appareil** via `SharedPreferences`. Elles ne sont jamais envoyées à nos serveurs.

---

## 3. Ce que nous NE collectons PAS

Nous tenons à être clairs : Nouchi Gospel **ne collecte pas** :
- Votre position GPS
- Votre carnet de contacts
- Vos photos ou médias
- Votre microphone
- Votre historique de navigation
- Vos informations bancaires ou de paiement (l'application est 100% gratuite)
- Vos mots de passe (l'authentification Google est gérée par Google, pas par nous)

---

## 4. Comment nous utilisons vos données

Nous utilisons vos données uniquement pour :
1. Faire fonctionner l'application (afficher les versets, synchroniser vos préférences)
2. Vous envoyer les notifications que vous avez acceptées
3. Améliorer l'application (correction de bugs, nouvelles fonctionnalités)
4. Répondre à vos demandes si vous nous contactez

**Nous ne vendons JAMAIS vos données à des tiers. Nous ne les utilisons pas à des fins publicitaires.**

## 6. Stockage et sécurité

Vos données sont stockées sur les serveurs sécurisés de **Google Firebase**, qui respectent les normes internationales de sécurité (chiffrement en transit et au repos).

Malgré toutes les précautions, aucune transmission sur Internet n'est 100% sécurisée. Nous nous engageons à utiliser les meilleures pratiques, mais nous ne pouvons garantir une sécurité absolue.

---

## 7. Durée de conservation

- **Données de compte** : conservées tant que votre compte existe. Si vous supprimez votre compte, elles sont effacées sous 30 jours.
- **Token FCM** : supprimé automatiquement dès que vous désinstallez l'application ou désactivez les notifications.
- **Données techniques anonymes** : conservées jusqu'à 14 mois maximum (politique Firebase par défaut).
